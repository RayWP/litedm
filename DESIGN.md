# LiteDM interface direction

Reading this as: a desktop download utility for a learner and everyday Windows user, in a calm light blue and silver native Windows style, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

The user selected light blue and silver. The app should feel familiar, readable, and compact while making active transfers easy to find.

- Light blue `#DCEFFC` groups transfer activity without competing with filenames.
- Silver `#E8EDF2` separates supporting controls and status from the primary workspace.
- Dark ink `#17324D` keeps text readable; strong blue `#2563A6` identifies the main action.
- System typography follows Windows text scaling and keeps the app familiar.
- Uniform rows make progress and file states easy to compare. This repetition is intentional for a utility list.
- Spacing separates the add-link controls, transfer list, and overall status; no marketing sections.
- Native control states and progress indicators provide feedback. Decorative animation is unnecessary.
- Light is the default; dark and system appearances remain selectable and use equivalent blue/silver resources.
- Only functional symbols are used. Any temporary app/tray icon is identified as a development placeholder.

The main action is Add download. The active download's progress is the focal point once work begins. Every control must have a real behavior, keyboard access, and a visible error path.
